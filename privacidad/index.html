Política de Privacidad

Vigente desde el 13 de agosto de 2026

La aplicación utiliza únicamente la información necesaria para conectar cuentas y ejecutar las publicaciones solicitadas.

1. Información tratada

  • Identificadores básicos, nombre visible y datos de perfil facilitados por la plataforma conectada.
  • Tokens de autorización necesarios para operar con las APIs oficiales.
  • Archivos, títulos, descripciones y ajustes elegidos para una publicación.
  • Información técnica mínima necesaria para diagnosticar errores y proteger el servicio.

2. Cómo se utiliza

Se utiliza para autenticar tu cuenta, preparar el contenido, enviarlo a la plataforma elegida y comunicar el resultado.

3. Contraseñas

No solicitamos ni almacenamos contraseñas de redes sociales. El inicio de sesión ocurre en la pantalla oficial de cada proveedor.

4. Archivos y publicación

Los archivos se procesan solo para la acción solicitada y se comparten con la plataforma cuando confirmas la publicación.

5. Proveedores externos

Cada red social procesa la información conforme a su propia política. No vendemos tus datos personales ni los utilizamos para publicidad ajena.

6. Conservación y seguridad

Las credenciales de acceso se conservan protegidas durante el tiempo necesario para mantener la conexión autorizada.

7. Tus controles

Puedes desconectar una cuenta, revocar el acceso y retirar un archivo antes de publicar.

8. Menores de edad

La aplicación no está dirigida a menores que no tengan la edad necesaria para gestionar cuentas según las condiciones aplicables.

9. Cambios

Actualizaremos esta política si cambian las funciones, plataformas integradas u obligaciones aplicables.

10. Contacto

Las solicitudes de privacidad podrán enviarse mediante el canal de soporte que se habilite dentro de la aplicación.
